# epupp

Browser tampering and userscript development with Epupp (ClojureScript/Scittle in the browser).

Version: 0.1.4

## Skills

### epupp

Teach Epupp as one system: a Scittle page program reached through the panel, the live REPL, and userscript injection, with extension memory and script composition. Use when: Epupp, live tamper, userscripts, a browser page REPL, epupp.fs, epupp.storage, epupp.tools, :epupp/inject, Scittle in the browser, or a Backseat Driver session named epupp-default or epupp-<site>.
